# 📈 AI-Powered Demand Forecasting System

An interactive machine learning application for analyzing historical demand data and predicting future product demand.

## 🚀 Overview

The **AI-Powered Demand Forecasting System** is a Python-based application developed to analyze historical product demand and generate future demand predictions.

The project combines data preprocessing, data analysis, machine learning, forecasting, and interactive visualization to help users understand demand patterns and support data-driven planning.

The application is built using **Python and Streamlit**, with analysis and experimentation performed using **Jupyter Notebook**.

## 🎯 Objectives

- Analyze historical product demand data
- Identify demand trends and patterns
- Predict future product demand
- Visualize historical and predicted data
- Provide an interactive forecasting interface
- Support data-driven demand and inventory planning
- Reduce manual effort in demand analysis

⚙️ Installation
1. Clone the Repository
git clone https://github.com/Naveenkumar210225/Demand-Forecasting-System.git
2. Navigate to the Project Directory
cd Demand-Forecasting-System
3. Install Required Libraries
pip install streamlit pandas numpy scikit-learn matplotlib seaborn openpyxl
▶️ Run the Application

Start the Streamlit application using:

streamlit run Forecasting.py

After running the command, Streamlit will provide a local URL.

Usually:

http://localhost:8501

Open the URL in your browser to access the application.

📌 Application Modules
